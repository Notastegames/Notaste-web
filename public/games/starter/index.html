Example game

Catch the paperwork. File it before the coffee gets it. None of it will be read. This is the example new Notaste games are built from.

Notaste GamesFree play

How to play

  • Move the tray with the arrow keys, the mouse or a finger, and catch the forms as they fall.
  • File the stack with Space, a click or the File button. Bigger stacks score more. Twelve and it falls over.
  • Coffee soaks anything you haven't filed. Today's run drops the same paperwork for everyone.
